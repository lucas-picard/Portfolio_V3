BLOC 3 : UN POINT TECHNIQUE

Problème : Les kata Codewars sont exécutés dans un environnement qui fournit généralement des tests et un cadre d'exécution prédéfini. Pour les lancer localement dans un terminal, certaines solutions doivent être adaptées afin de gérer les entrées, les appels de fonctions et l'affichage des résultats.

Solution : Ajouter le code nécessaire à l'exécution autonome des exercices, notamment un point d'entrée adapté et, lorsque nécessaire, des tests permettant de vérifier les résultats. Cette adaptation permet de compiler ou d'exécuter les solutions localement tout en conservant leur logique algorithmique.
